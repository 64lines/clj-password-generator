# Clojure Password Generator

A password generator written in Clojure on which you can create passwords with or lack of special characters.

## Run

Run including special characters:
```sh
lein run
```

Run without special characters:
```sh
lein run --no-special-chars
```

## Compile

You can compile the program with the following command:
```sh
lein uberjar
```
